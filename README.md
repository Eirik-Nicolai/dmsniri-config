
# EIRIK's conifg for DMS/NIRI

This repo contains keybindings themes and config for various parts of NIRI/DMS


## OTHER PLUGINS/PACKAGES
### Packages
- wofi                         - sudo apt-get install wofi
    Application Launcher
- qimgv                        - sudo apt-get install qimgv
    Image viewer
- ghostty                      - https://ghostty.org/
    ghostty doesn't play nice with dead keys, there's a config fix included or 
    you need to install ibus
- yazi                         - https://github.com/sxyazi/yazi
    File manager
- hyprlock                     - sudo apt-get install hyprlock
    Screen lock manager        (config: https://github.com/mahaveergurjar/Hyprlock-Dots)


### Plugins
- bongoCat                     - dms plugins install bongoCat
    Seratonin
- catWidget                    - dms plugins install catWidget
    Dopamine
- quickCapture                 - dms plugins install quickCapture
    Spectacle for Wayland
- DMS greeter (if wished)      - dms greeter install
